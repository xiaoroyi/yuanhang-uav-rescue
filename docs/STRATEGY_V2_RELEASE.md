## 使用

更新并重新启动服务，打开http://127.0.0.1:8000。旧方案会标明“旧版延期优先v1”，点击“按新规则重新计算”；随后在同一快照分别计算其他偏好。顶部新计算使用v2，深入优化与事件重规划继承所选Plan版本。

侧栏“调度安排”或工作台“查看调度安排”进入安排表，选方案、按机体筛选，点击行查看逐站箱件与资源时间轴；“在地图中定位”回工作台。导出当前安排CSV只导出当前筛选与当前表，不覆盖输入。背景开关位于顶部星光图标；系统减少动态效果开启时背景静止。

## 边界

服务区基本保障公平仍待定义基本保障数量/门槛与独立验收，不把现有时间能耗折中包装成公平调度。费用仍未配置；有限候选结果不是全局最优。既有仅零时刻重规划、卫星需联网/实际浏览器联网受限、多用户认证未实现等边界沿用原交接。
