## 源码发现

- `问题1/src/data_io.py` 从 `PROJECT.parent/D题` 查输入；`bootstrap.py` 依赖旧目录结构。
- `问题2/src/env.py`、`问题3/src/setup_q3.py` 修改 sys.path 并在导入时创建 results。直接 import 会产生副作用。
- Q3 setup 硬编码中继数量、组件数量等原题常数，不能直接作为任意现场资源输入。
- 最终提交的 Q2 master 比旧 `问题2/src/master.py` 更完整；跟随提交版和发布包，不能随便拿旧文件替代。
- 源码调用 numpy、scipy、openpyxl、pyproj、shapely、OR-Tools，包含 Shapely 2 风格API；本轮没有安装这些业务依赖，也未确认原版本锁定。
- .mat DEM 是旧读取链路的重要输入，.tif 留作后续GIS；新区域投影不固定套用 UTM49N。
