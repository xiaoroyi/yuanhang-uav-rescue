# 可复现策略矩阵

这是软件策略的重复性与约束核查实验，不是算法优越性或学习泛化证明。实施前固定如下协议，实际原始结果另存evidence/experiments，不用正文中的期望填充结果。

输入取原始5点32箱、15点80箱，以及增加1准备位/2充电端口的32箱配置。每个输入创建一个不可变Snapshot，三个策略time/energy/balanced共享其内容hash；种子固定7、42、2026，每个组合预算15秒，共27次真实求解。每个种子循环轮换策略执行顺序，不只挑选某个有利种子。

共同首要指标为逐箱优先级加权期望延期。各策略第二目标分别为最后返航、运输能耗、最后返航+300×运输能耗（与代码一致）。另外记录最后交付、架次数、最低返航SOC、运行耗时、首个可行时间、候选数与独立验证。硬截止违约不可当作可接受的指标改善。

每次保留完整Options与Outcome，成功Plan重新独立验证；UNKNOWN和其他失败均保留诊断，汇总表使用空值而不是0。汇总只在同一输入内按策略计算可行次数及各指标的min/median/max，不把不同输入或不同目标的数值当成同条件算法改进。

实验在单个Python进程顺序运行，排除HTTP/Worker启动时间。地形缓存可能变热，执行顺序轮换只能减轻部分顺序效应；本机不保证无其他进程负载。因此运行秒数只作本次记录，不作严格机器性能结论。记录Python/平台、Git、源码指纹、输入hash、时间与种子；全局最优、最少增配、随机成功概率和真机精度均不在此实验声明范围内。

额定单点已有逐箱/贪心基线，动态调度已有同预算局部/全量对照，它们各自遵循不同模型，不能混为一张“算法优越”排名。该矩阵也不能代替更充分的独立数据、消融和外部场景实验，Q-02/A-13的未完成范围继续保留。
