# RFC-027：冻结的执行影响图与方案有效性

消费者与专项已验，待最终全量。ExecutionEventView兼容增加可空impact：冻结事件时刻/事实游标，节点同时保留plan_id与sortie_id，node_id为二元素JSON数组字符串；不能把相同原始架次ID的不同Plan合并。边仅表示按原时序排列的机体/运输电池资源后继，direct/affected/committed分别表示直接命中、资源传播和已有装载事实承诺。旧数组仍为原始ID投影，跨Plan精确身份以新节点为准；旧事件无图时显示未保存，不反推伪造历史。

有限地面资源标记保守共同释放边界，不造不存在的工位分配边；联合通信窗口依赖尚未纳入本图。图为变化定位诊断，不等同于实际新Plan、物理可行性认证或最小改动证明。旧Plan仍只对冻结Snapshot有效，当前执行有未处理事件时规划页面显示专门入口，不修改历史validation状态。

事件存储原图，完整执行包导出引用节点所需原文，导入按原Plan重建资源边、闭包及事实承诺，拒绝篡改引用和传播。HTTP路径保持不变，严格模型/操作Schema/OpenAPI/TypeScript同批更新。
