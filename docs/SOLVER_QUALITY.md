# 候选覆盖与策略比较

快速求解使用同一构造组合：按相同种子序列轮流用时间、能耗、均衡偏好生成候选，再按所选策略的共同字典序评分选择。提前停止依据共同的优先级加权延期，连续12次未改善后停止，最多48次；不会因某一个策略的次目标不同而提前停止另一套候选序列。墙钟预算、硬件负载或失败候选仍可能截断搜索，因此不保证两次限时计算访问完全相同的候选，也不保证能耗与时间各自全局最优。

同一需求有超额库存时，先考虑实际可用机队和兼容电池支持的载重/体积，再按质量与体积占比选择箱件。多起点改变二者权重，不能只取字典序最小的箱号而忽略更轻、可装载的替代箱。未选箱件留在库存；需求数量、目的地和货物类型仍由契约与独立检查约束。该筛选不是完整背包优化或不可行证明；没有找到候选仍返回UNKNOWN。

回归包含“首个箱号超载，但同一需求有可运输替代箱”以及搜索完整结束时的共同候选组合比较。此前evidence/solver中的实测文件保留其当时算法和预算，不视为后续版本的固定输出或性能保证。
