# V4 本机演示

在仓库根目录运行：

```powershell
.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开http://127.0.0.1:8000/。前端已构建时由后端一起托管。已有8000服务时不要重复启动。开发方式与依赖安装见根README；个人runtime不随GitHub分发。

1. 首页查看真实地形主视觉，可切换只看地形并关闭动效；通过“进入演练案例”查看四类任务和数据来源。
2. 首次选“山地断路”，使用案例生成独立救援任务。完成任务准备与条件检查，输入修改要保存。
3. 方案规划中默认“标准调度”。可选“EOH增强”和本地评分包；点击“对比两种引擎”在同快照下真实计算。它是搜索偏好的对照，可能得到相同结果，不保证提升。
4. 看地图、独立“调度安排”、逐箱/架次、资源时序、三维与剖面；可导出Excel。引擎横条和比较页显示来源及实际调用数。
5. 确认通过检查的方案，到执行跟踪创建模拟实例并启动/暂停。机队看板查看运输、返航、下一任务和模型预测数据。动态修改仍走原事件→影响→计算→差异→采纳。
6. 案例与档案页查看最近任务、完成/归档和输入复用。复制输入产生新任务，不继承旧交付。
7. 算法引擎页可导入/导出本地JSON策略包；设置与接入页可下载配置、OpenAPI和查看适配路径。外部模型与真机本轮均不连接。

换电脑携带任务与本地策略时，用`scripts/backup.py`的一致性备份及新目录恢复；不要直接拷贝正在写入的SQLite文件。视频图文教程在“使用帮助”。
